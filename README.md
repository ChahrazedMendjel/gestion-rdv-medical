# 🩺 DoctorLite — Appointment and Patient Progress Tracker

DoctorLite is a lightweight desktop application developed in **Java** to help doctors efficiently manage their **appointments** and **patient records**. With a simple and intuitive interface, this app allows medical professionals to schedule consultations and track patient progress with ease.

## ✨ Features

- 📅 Schedule, view, and manage doctor appointments  
- 👨‍⚕️ Store and update detailed patient information  
- 📈 Track patient progress over time  
- 💾 Save and load data for future access  

## 💻 Built With

- Java (Core language)  
 -Scene builder
